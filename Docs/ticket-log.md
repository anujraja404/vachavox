# Ticket Log

Minimal personal ticket tracker for a single-developer project.

## Usage

- Create one short ticket ID per change (example: `VV-2026-04-28-01`).
- Keep each row to one line and link to details in commits, changelog, or notes.
- Mark `Done` once shipped in a version/build.
