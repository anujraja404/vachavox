# Privacy

VachaVox is designed as a local-first dictation app.

- Audio is captured only while dictation is active.
- Transcription runs on device through FluidAudio and Core ML.
- No audio or transcript data is uploaded by the app.
- Dictation transcript history is not stored automatically.
- File Transcription creates explicit user-generated Markdown files under `~/vachavox/output`.
- Clipboard output is explicit and local.
- Accessibility is requested only for paste mode.
- Analytics are not included.
